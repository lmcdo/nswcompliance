# SEPP Structured Requirements - Data Structure Fix

## Problem Identified

The contamination SEPP data in `sepp_structured_requirements` table has the WRONG structure.

**Error**: `TypeError: Cannot read properties of undefined (reading 'map')`  
**Cause**: Contamination data missing `categories` array that component expects

## Data Structure Comparison

### CORRECT Structure (Energy/Lighting)
```javascript
{
  title: "Energy Efficiency & Lighting Requirements",
  description: "...",
  categories: [  // <-- REQUIRED ARRAY
    {
      name: "Lighting Efficiency",
      reference: "Schedule 2, Section 4",
      requirements: [
        { requirement: "...", definition: "..." },
        { area: "...", standard: "..." }
      ]
    }
  ]
}
```

### WRONG Structure (Current Contamination)
```javascript
{
  title: "Preliminary Contamination Investigation Required",
  description: "...",
  trigger_conditions: [...],  // <-- NOT categories array
  zone_risk_indicators: {...},
  feasibility_impact: {...},
  compliance_requirements: [...],
  pdf_references: [...],
  external_resources: [...]
}
```

## Component Expectations

`StructuredSeppRequirements.tsx` expects ALL requirements to have:

```typescript
interface RequirementData {
  title: string;
  description?: string;
  categories: RequirementCategory[];  // REQUIRED
}

interface RequirementCategory {
  name: string;
  reference: string;
  requirements: RequirementItem[];
  legal_citation?: string;
}
```

## How to Fix

**Option 1: Run the fix script** (requires database access)
```bash
cd frontend-nextjs
node fix_contamination_structure.mjs
```

This will UPDATE the existing contamination record to have proper `categories` array.

**Option 2: Manual database update**
```sql
UPDATE sepp_structured_requirements
SET requirement_data = '{
  "title": "Preliminary Contamination Investigation Required",
  "description": "...",
  "categories": [
    {
      "name": "When Investigation is Required",
      "reference": "SEPP R&H 2021, Section 4.6(4)",
      "requirements": [...]
    },
    ...
  ]
}'
WHERE sepp_id = 'resilience_hazards_2021' AND section = '4.6';
```

## Files to Check

3. `insert_sepp_energy_lighting.py` - Example of CORRECT structure

## Why This Happened

The contamination data was manually created with a custom structure optimized for displaying contamination-specific info (costs, zones, timelines), but it doesn't match the generic `categories` array structure that the React component expects for ALL SEPP requirements.

## Prevention

All future SEPP structured requirements must follow the SAME format:
- title (string)
- description (optional string)
- categories (REQUIRED array of category objects)

Use `insert_sepp_energy_lighting.py` as the template!
