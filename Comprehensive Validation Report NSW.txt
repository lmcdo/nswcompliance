3.3 Multi-Storey Building Separation Standards (NSW Apartment Design Guide)

Legal Authority & Statutory Basis

Source: NSW Apartment Design Guide - Part 3: Siting the Development
Section: 3F-1 Visual Privacy - Design Criteria 1
Authority: State Environmental Planning Policy (Housing) 2021
Legal Status: STATUTORY (not guidance)
Published: March 2023 by NSW Department of Planning
URL: https://www.planning.nsw.gov.au/sites/default/files/2023-03/apartment-design-guide-part-3-siting-the-development.pdf

Professional Context:

For multi-dwelling housing, residential flat buildings, and shop-top housing developments (3+ dwellings), the Apartment Design Guide (ADG) provides STATUTORY building separation standards that apply across all NSW councils. These standards override local DCP setback provisions for upper floors of multi-storey developments.

Critical Distinction - When ADG Standards Apply:

Development Type          ADG Applies?    Authority Level
──────────────────────────────────────────────────────────
Dwelling house (1-2 storey)    ❌ No      DCP setbacks apply
Dual occupancy                 ❌ No      DCP setbacks apply
Multi-dwelling housing         ✅ YES     ADG Section 3F-1 (STATUTORY)
Residential flat building      ✅ YES     ADG Section 3F-1 (STATUTORY)
Shop-top housing               ✅ YES     ADG Section 3F-1 (STATUTORY)

Statutory Building Separation Table (ADG Section 3F-1, Page 63):

Building Height         Habitable Rooms      Non-Habitable Rooms
                        & Balconies          (bathrooms, storage)
────────────────────────────────────────────────────────────────
Up to 12m (4 storeys)         6.0m                  3.0m
Up to 25m (5-8 storeys)       9.0m                  4.5m
Over 25m (9+ storeys)        12.0m                  6.0m

Note: These are distances to the side or rear boundary. Between buildings on the same site, the distances combine (e.g., 6m + 6m = 12m separation between habitable windows).

  def is_query_dangerous(self, sql: str) -> bool:
      sql_upper = sql.upper().strip()

      # Absolutely forbidden operations
      forbidden = [
          'DROP DATABASE',
          'DROP SCHEMA',
          'TRUNCATE',
          'DELETE FROM',        # Without WHERE
          'UPDATE WITHOUT WHERE',
          'ALTER DATABASE',
          'GRANT ALL',
          'REVOKE',
      ]

      for dangerous in forbidden:
          if dangerous in sql_upper:
              print(f"DANGEROUS QUERY BLOCKED: {dangerous}")
              return True

      # Check for DELETE/UPDATE without WHERE
      if 'DELETE FROM' in sql_upper and 'WHERE' not in sql_upper:
          print("DELETE without WHERE clause blocked")
          return True

      if sql_upper.startswith('UPDATE') and 'WHERE' not in sql_upper:
          print("UPDATE without WHERE clause blocked")
          return True
