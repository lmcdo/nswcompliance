Key Internal Structure Changes:

✓ 4-Level Hierarchy (Consistent across all tabs):
  1. 1. Status Bar - Quick summary in light card color (purple-50, amber-50, green-50)
  2. 2. Primary Content - Main info on white background (structure varies by card)
  3. 3. Supporting Info - Context/guidance in colored box with left border
  4. 4. Actions - Links/buttons in gray footer with border-top
✓ DCP Color Changes (Purple → Green):
  • • C/O control marker badges: bg-purple-100 → bg-green-100
  • • "Precinct Character" badges: Purple → Green
  • • Supporting info boxes: Purple border → Green border
  • • All icons and links: Purple → Green
✓ E&C Card (Keep Emerald):
  • • Maintains emerald theme (special certifier gateway status)
  • • Workflow guidance uses amber (cross-tab reference)
  • • Otherwise follows 4-level pattern
✓ Supporting Info Boxes:
  • • E&C workflow guidance: Amber (references LEP/DCP tabs)
  • • BASIX notes: Purple (matches SEPP theme)
  • • LEP land use notes: Amber (matches LEP theme)
  • • DCP precinct context: Green (matches DCP theme)
✓ Consistent White Space:
  • • Status bar: px-4 py-3
  • • Primary content: p-4
  • • Supporting info: mx-4 mb-4 p-3 (inset from edges)
  • • Actions footer: px-4 py-3
