Rationalized Information Architecture

Tab color = source authority. Structural levels = consistent visual hierarchy.

Core Principles
  • Tab Color: Indicates source authority (SEPP=purple, LEP=amber, DCP=green)
  • All cards within a tab use that tab's color for accents (badges, boxes, highlights)
  • Structural hierarchy is consistent: Level 1 (light gray bg) → Level 2 (white) → Level 3 (tab-color box) → Level 4 (gray footer)
  • Result: Clear visual structure + clear source attribution
