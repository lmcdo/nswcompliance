## 0. Mount structure (drives WHEN calls fire)

- Page = `app/assessment/page.tsx`. Default `viewMode='sepp'` (hooks/useAssessmentUI.ts:32). Tabs: **SEPP**, **Planning Controls (lep)**, **DCP**. No "Overview" tab exists.
- SEPP tab: `StateLevelControls` mounted ONLY while `viewMode==='sepp'` (page.tsx:576). Switching away unmounts; coming back re-fires its calls.
- LEP tab: `LepControls` mounted ONLY while `viewMode==='lep'` (page.tsx:589). Its calls do NOT fire until the Planning Controls tab is clicked.
- DCP tab: panel is ALWAYS mounted (CSS `hidden` only, page.tsx:608). `ProvisionsByTocStructure` mounts as soon as `!loading && SP` if `isDcpEnabledForCouncil()` (page.tsx:620; env `NEXT_PUBLIC_DCP_ENABLED==='true'`, optional `NEXT_PUBLIC_ENABLED_LGAS`). The `dcpEverActivated` "lazy mount" state (page.tsx:143) is set but NEVER read as a gate, so **DCP calls fire on property load, before the DCP tab is clicked**. Otherwise `DCPInterestForm` renders (no data calls on mount).
- Left column (always, once SP present): header pill, Property Summary, AerialTile, PropertyDetailsComprehensive, SpatialContextCard (flag-gated, button), InstrumentCurrency.
- Never mounted / dead (do not capture): Zone-info modal (page.tsx:658; `setShowZoneInfo(true)` is never called), `useFullPropertyData`, `useCrossReferences` (CrossReferenceList never receives `crossReferencesMap`), `MinimumLotSizeCard`, `ADG separation table card`, `PropertySearch` data fetches (Google Places JS only), `useCdcSetbacks`, `/api/cdc/compliance-check` (calculator never calls `submit`).
- Env/flag gates the replayer must know: `NEXT_PUBLIC_DCP_ENABLED`, `NEXT_PUBLIC_ENABLED_LGAS`, `NEXT_PUBLIC_FEATURE_SPATIAL_CONTEXT_CARD`, `NEXT_PUBLIC_SPATIAL_API_URL` (StateLevelControls:397), `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` (frontend-nextjs/app/layout.tsx:111).
- Double-fire hazard: `developmentType` starts `'dwelling_house'` and is overwritten by zone (see Table D) AFTER first render with SP; `isLMRArea` starts null then true/false; `stationDistance` changes when transport loads. Calls with those in deps can fire 2-3x per address; replay should key on (route + final body) and take the LAST.

## Surprises / likely cross-surface disagreement sources

1. DCP tab calls (#4, #5) fire on property load, not on tab click (`dcpEverActivated` never gates the mount).
2. `/api/capacity/calculate` result (`lepClauseData`) is read as `.height_limit` / `.fsr` (ProvisionsByTocStructure.tsx:2012, 2452; DAModeCard:166) but the route returns `capacity.maxHeight/maxFSR`; those fields do not exist, so those DA-mode chips are always empty. Its `setbacks`/`parking`/`landscaping` are never displayed on the live page.
3. `constraints.floodProne` is hard-coded false (nsw-planning-portal.ts:745) and never set true. It feeds (a) the DA-intake auto-answer `flood_prone='no'` (lib/see/intake.ts:432) which makes the flood topic "not applicable"/greyed in the DCP tab for every property, and (b) Pattern Book's flood exclusion (check-exclusions.ts:64) which never triggers.
