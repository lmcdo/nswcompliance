# Product Demo — 90 Seconds — Text Overlay Only
## verify.plotdetect.com.au
## Format: No narration. Text overlays carry all meaning. Works on mute.
## Audience: Architects, town planners, developers, council officers

---

### Framing principle
Audience knows the domain. Don't explain what FSR or BASIX is.
Overlays interpret significance, not content — the screen shows content.
Connecting thread across tabs: SEPP answers CAN YOU. LEP answers WHAT LIMITS. DCP answers HOW EXACTLY.

### Production notes
- No voiceover. Music optional (ambient, not distracting).
- Text overlay timing: hold interpretive lines 1.5–2 seconds longer than feels natural.
- Clause 6.20 badge moment at 0:34: slow mouse movement, hold on red badge before overlay appears.
- Excluded topic label moment at 0:52: pause on the list so viewer reads it.
- Do not rush tab transitions — each tab change is a visual beat.
- Pre-load session with dev type set, 3 provisions pre-marked so PDF export looks substantive.
- Total: 90 seconds.
