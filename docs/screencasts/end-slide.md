## SLIDE 2 — What Certifiers Deal With Every Day

*Every one of these. Answered before you pick up the phone.*

### The CDC call — builder wants a fast answer
- "Can this go CDC or does it need a DA?" → instant pathway determination
- "It's in a heritage area — which HCA, and does it block CDC?" → HCA identified, SEPP Housing exclusion cited
- "What Part 6 clause blocks it? I need to tell the owner exactly why." → clause number + PDF page, cited
- "Is it the LEP or the SEPP blocking it?" → SEPP tab vs LEP tab makes the source clear

### Heritage — what actually applies here
- "Is this a heritage item, or just in a conservation area?" → heritage item status and HCA shown separately
- "Which HCA is this in and which chapter of the DCP governs it?" → HCA name, DCP chapter, section number
- "Solar panels on the rear slope — what do the heritage controls say?" → §8.1.7.3 ridgeline rule + HCA-specific controls surfaced
- "What does DCP say about alterations to this heritage item?" → filtered to §8.1.7 controls, all cited

### Setbacks and DCP compliance
- "What is the required rear setback for a single storey addition in this zone?" → DCP provision with section number and PDF page
- "It's a corner lot — which setback rule applies?" → corner lot detected, secondary street setback (3m) triggered automatically
- "What are the precinct-specific controls for this address?" → precinct matched, precinct provisions filtered and shown

### Site constraints — instant
- "Is this lot flood affected?" → yes/no from live NSW Planning Portal
- "Acid sulfate soils — which class?" → class shown
- "BASIX water target for this climate zone?" → shown on property card
- "Heritage item on the adjoining lot — what controls apply to my development?" → §8.1.7.2 Development in the vicinity of a heritage item surfaced

### When you need the legal basis on record
- "Council is challenging my CDC — what is the exact legislative basis?" → LEP clause + SEPP clause + PDF page, all cited
- "There's a discrepancy between the LEP I checked and Planning Portal — which is current?" → app pulls live from NSW Planning Portal spatial API
