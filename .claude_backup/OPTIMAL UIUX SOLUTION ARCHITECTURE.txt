  🎯 KEY UX PRINCIPLES

  1. 🏃‍♀️ SPEED OVER COMPLETENESS

  - Show essentials first, details on demand
  - Legal text available but not overwhelming initial view
  - Quick actions prominently placed

  2. 🧭 CONTEXT-AWARE INTERFACE

  - SEPP provisions highlighted (they override everything)
  - Conflict detection built into layout
  - Related provisions easily discoverable

  3. 📚 RESEARCH-OPTIMIZED

  - Legal text formatted for readability
  - Cross-references clearly linked
  - Extract/export tools for documentation

  4. 💡 PROGRESSIVE EXPERTISE

  - Novice: Simple constraint list with guidance
  - Intermediate: Full constraint details with legal access

  - Expert: Advanced analysis tools with bulk operations

  This design provides maximum legal text accessibility
  while minimizing screen clutter and optimizing for actual
   planner research workflows.
