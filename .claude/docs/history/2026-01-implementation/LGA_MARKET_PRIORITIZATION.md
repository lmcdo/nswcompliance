# LGA Market Prioritization: 10-12 Sydney Metro Councils
## Data-Driven Selection for Maximum ROI

**Date:** 2026-01-30
**Context:** Identify highest-value LGAs for PlotDetect expansion
**Methodology:** DA volume + property values + strategic fit

---

## Scoring Framework

Each LGA scored on 3 criteria (0-10 scale):

1. **Market Value (0-10)**
   - DA volume (annual DAs lodged)
   - Average property value
   - Development activity (approvals, construction)

2. **Complexity (0-10)**
   - DCP structure complexity (simple = higher score)
   - Number of precincts/overlays
   - Heritage/environmental constraints
   - *Note: Higher score = EASIER to implement*

3. **Strategic Fit (0-10)**
   - Adjacent to Inner West (existing coverage)
   - Partnership opportunities (council relationships)
   - User demand (architect/certifier requests)
   - Brand alignment (premium vs volume market)

**Total Score:** Market Value × 1.5 + Complexity × 1.0 + Strategic Fit × 1.0 (max 40)
