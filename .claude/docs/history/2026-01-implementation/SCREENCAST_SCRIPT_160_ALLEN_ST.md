## COMMON MISTAKES TO AVOID

❌ **Don't:**
- Scroll too fast (viewers need time to read)
- Click randomly without explaining
- Show loading states longer than 1-2 seconds
- Use jargon without context
- Rush through DCP features (that's the unique value)

✅ **Do:**
- Pause on key numbers (40%, 191m², Page 37)
- Explain WHY something shows or doesn't show
- Demonstrate actual interaction (click, filter, expand)
- Show the full PDF page image clearly
- End with clear value proposition
