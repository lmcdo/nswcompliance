## AI Chat Recording Tips

**Timing:**
- Allow 2-3 seconds for response to appear
- Can speed up in post-production if needed
- Pause cursor on citations for emphasis

**What to show:**
- Question being typed (not pasted)
- Loading indicator briefly
- Response appearing
- Citation links highlighted
- Source document reference

**What NOT to show:**
- Error states
- Slow responses (re-record if >3 seconds)
- Complex multi-part questions
