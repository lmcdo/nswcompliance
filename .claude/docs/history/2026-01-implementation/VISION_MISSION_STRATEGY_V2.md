## Vision

## Mission

## Platform Strategy

**Two pillars of property intelligence:**

| Pillar | Technology | Coverage | Status |
|--------|------------|----------|--------|
| **Regulatory Intelligence** | NLP + structured extraction | NSW (API-dependent) | Live |
| **Visual Intelligence** | SAM3 + computer vision | Anywhere with imagery | Planned |

### Why This Matters

**Regulatory Intelligence (NSW):**
- NSW Planning Portal API enables automated extraction
- Other states lack equivalent APIs - complicated for less return
- Focus depth over breadth: 48K provisions for Inner West alone

**Visual Intelligence (National/Global):**
- Satellite/aerial imagery available everywhere
- SAM3 enables property segmentation without state APIs
- Building footprints, setback measurement, tree canopy, structures
- Compliance verification from imagery (fence height, pool location, setbacks)

## Honest Limitations

### What We Can Deliver

| Type | Example | Confidence |
|------|---------|------------|
| Fixed values | "Rear setback: 8m" | HIGH |
| Calculated | "Side: 25% of 15m = 3.75m" | HIGH (with lot data) |
| Regulatory text | Full DCP clause with citation | HIGH |

### What Requires Professional Judgment

| Type | Example | Our Approach |
|------|---------|--------------|
| Streetscape-relative | "Consistent with established character" | Show text, flag as interpretive |
| Map-based | "Refer to Figure 4.2" | Link to DCP, show as "requires manual lookup" |
| Performance-based | "Adequate privacy separation" | Show text, recommend professional |

**~70% of provisions are calculable. ~30% require interpretation.**

We're honest about this. Professionals value the time saved on the 70%.

## Visual Intelligence Roadmap (SAM3)

### What SAM3 Enables

| Capability | Input | Output | Use Case |
|------------|-------|--------|----------|
| **Property segmentation** | Aerial/satellite image | Building footprint, boundaries | Any property, any state |
| **Structure detection** | Property image | Pool, shed, carport, granny flat | Compliance verification |
| **Setback measurement** | Aerial + cadastre overlay | Distance from boundaries | Automated setback check |
| **Tree canopy analysis** | Aerial image | % coverage, protected trees | Environmental compliance |
| **Roof analysis** | Aerial/drone image | Condition, solar potential | Valuation, sustainability |
| **Change detection** | Historical vs current | New structures, modifications | Unauthorized works detection |

### Why Visual Intelligence Expands Addressable Market

| | Regulatory Intelligence | Visual Intelligence |
|---|------------------------|---------------------|
| **Coverage** | NSW only (API-dependent) | Australia-wide (imagery available) |
| **Data source** | Planning Portal APIs | Nearmap, Google, NSW Spatial |
| **Barrier to entry** | High (extraction expertise) | Medium (CV/ML expertise) |
| **Competitors** | Few (data moat) | More, but can differentiate |

### Integration Points

```
User enters address
       │
       ├─► Regulatory data (NSW)
       │   └── Zoning, FSR, setbacks, DCP provisions
       │
       └─► Visual data (Anywhere)
           ├── Building footprint from SAM3
           ├── Calculated setbacks from imagery
           ├── Structure detection (pool, shed, etc.)
           └── Tree canopy %

Combined output:
"Your property has a 85sqm building footprint, 3.2m from rear boundary.
 DCP requires 6m rear setback. Potential non-compliance detected."
```

### Phased Rollout

**Phase 1:** NSW regulatory intelligence (current)
**Phase 2:** SAM3 building footprint extraction (proof of concept)
**Phase 3:** Setback measurement from imagery + cadastre
**Phase 4:** Structure detection for compliance verification
**Phase 5:** National rollout (visual-first for non-NSW states)
