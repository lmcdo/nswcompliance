## KEY FEATURES TO HIGHLIGHT VISUALLY

### 1. **Planning Portal Left Column**
- Show real-time query animation
- Highlight data sources: SEPP layers, LEP clauses, LGA boundaries

### 2. **SEPP Section**
- **BASIX card**: Water/Energy/Thermal targets with climate zone map
- **Housing Reforms card**: Visual comparison of eligible vs ineligible housing types
- **Contamination**: Show "Chapter 4 applies" with link to requirements

### 3. **LEP Section**
- **Key Sites Map visual**: Show property highlighted on map overlay
- **Clause 6.16 PDF**: Actual PDF page image display
- **Nearby Key Sites collapsed**: Show "Nearby Key Sites (2)" with subtle styling

### 4. **DCP Section**
- **Filter dropdown**: Show topic categories
- **Layer tabs**: TOC | By Topic | By Page
- **PDF citations**: Highlight clickable page numbers that open extracts
- **Page grouping**: Show "Page 7 - 3 provisions" grouped together

### 5. **Interactive Elements**
- Expandable cards (chevron icons)
- Clickable PDF citations
- Filter dropdowns
- Collapsible nearby provisions
