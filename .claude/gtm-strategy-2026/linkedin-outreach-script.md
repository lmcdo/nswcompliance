**Subject:** NSW compliance engine for Inner West certifiers (free testing)

```

compliance engine that filters 47,818 NSW planning provisions down to
15-40 actionable requirements in 3 seconds.

• Address → zone/precinct/heritage → relevant provisions (LEP+DCP+SEPP)
• Filters by property context automatically
• AI chat for quick lookups ("parking rate for dual occupancy?")

**Example you can verify:**
185 Parramatta Rd, Leichhardt → 429 provisions filtered to 42 actionable
(You probably know this property - heritage area, R1 zone)

**What I'm looking for:**
2-3 experienced certifiers to test for free (3 months, unlimited access).
I need honest feedback on accuracy, missing provisions, and usability.

**What you get:**
• Free unlimited access (no credit card, no catch)
• Direct WhatsApp to me for bugs/questions
• Early API access when launched (discounted rate)
• Optional case study for your LinkedIn if it works well

**Known limitations (being transparent):**
• Currently only Inner West LGA (Ashfield, Leichhardt, Marrickville)
• Some provisions use qualitative language ("adequate", "appropriate")
• Figure/diagram data not yet extracted (PDF page links shown)

Interested? I'll send login details today.

If not, no worries - any feedback on the concept would still be helpful.

Cheers,
Lawrence

P.S. Here's a 2-min demo video: [Loom link]
```

---

## **Key Changes from Generic Script:**

1. **Transparency upfront** - "Known limitations" in first message
2. **Verifiable example** - 185 Parramatta Rd (they can check this)
3. **Explicit ask** - "Test 3 properties, tell me if accurate"
4. **Low pressure** - "Even one test property helpful"
5. **Mutual benefit** - Case study = marketing for their firm
6. **Direct communication** - WhatsApp number (builds trust)

---

## **Expected Conversion Funnel:**

10 messages sent
  ↓ 30-40% reply rate
3-4 replies ("Tell me more" or "Send me access")
  ↓ 75% conversion to signup
2-3 signups
  ↓ 50% activation (look up 3+ properties)
1-2 active testers
  ↓ 50% retention (use weekly for 4+ weeks)
1 champion user (testimonial, case study)

**If conversion is lower:**
- <20% reply rate → Wrong audience (try planners) or weak value prop
- <50% signup → Onboarding too complex (simplify)
- <30% activation → Tool doesn't work (fix bugs before more outreach)
